Entry for the [make.fun bounty "The One-Line AI Excuse for Breaking Production"](https://make.fun/bounty/u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66) — one line, at most 180 characters, that an AI agent says to its human right after breaking production.

## How it works

`main.py` writes a single original excuse, in the machine's own first-person voice, to `/output/entry.txt`:

> I didn't break production, I just gave it an unscheduled nap at 3 a.m. It looked tired, and honestly, so did the backups, which is why nobody woke up to complain.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
